# PDF Converter

Free Image, PDF & Word converter that runs entirely in the browser. Files never leave your device.

**Tools:** image convert (JPG/PNG/WebP/HEIC), resize to exact px/KB, scan to PDF, image ⇄ PDF, PDF ⇄ Word, Word → image, image → Word, PDF → text, OCR (English/Hindi/Gujarati), compress PDF, merge, split, organize pages, page numbers.

Installable as an app (PWA) and works offline after first use. Labels in English, Hindi and Gujarati.
